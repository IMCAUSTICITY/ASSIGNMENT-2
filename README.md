# Assignment-02 – CSS clip-path

A Sippline landing page built with HTML and CSS. The diamond-shaped photo frame, the corner shapes and the background shapes are all made with the CSS `clip-path` property.

**Live demo:** https://imcausticity.github.io/ASSIGNMENT-2/

## Run locally
Open `index.html` in a browser. Put the hero photo at `assets/hero.jpg`.
